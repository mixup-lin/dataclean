## 前端界面 UI/UX 优化（uiux-pro-max-cn 技能驱动）

### 评审结论
- 技术栈：服务端渲染原生 HTML/CSS + 一小段渐进增强 JS（执行等待层），Flask 可选、标准库 http.server 降级；无框架/无构建。
- 技能检索确认视觉方向为 Data-Dense Dashboard（蓝主色 #1E3A8A/#2563EB/#0EA5E9 + 琥珀高亮 #D97706，KPI 卡、数据表、网格），现有配色已高度吻合，未改色板。
- 关键问题：style.css 首行 Tailwind CDN @import 破坏「离线完整可用」且 Preflight 与自定义样式冲突（项目未用任何 Tailwind 类）；可交互元素无统一焦点环；触摸目标 <44px；单一响应式断点；无 reduced-motion；导航无 aria-current；extract.html 嵌套 label；错误提示无 role=alert。

### 落地改动
- `static/style.css`（主改动）：删除 CDN @import；新增语义色 Token 别名（--color-* / --focus-ring / --tap-min:44px / --mono）；统一 :focus-visible 焦点环（输入框保留自身边框提示并抑制 outline 避免双提示）；skip-link 样式；btn/nav/chip/tab/pager/view-controls 提升至 34-44px 触摸目标；checkbox/radio accent-color + 焦点环；.alert 加 4px 语义左边框 + ::before 符号（不只靠颜色）；响应式四档（≥1440 限宽 / ≤1024 / ≤980 / ≤600 手机紧凑横排控制器）；@media (prefers-reduced-motion: reduce) 关闭所有动画过渡。
- `webapp.py`：_nav 加 skip-link、`aria-label="主导航"`、active 链接 `aria-current="page"`、brand-mark `aria-hidden`、状态徽章 `role="status"`；/plan 校验错误与 /extract 抽取失败加 `role="alert"`；WAIT_HTML spinner 加 `aria-hidden="true"`。
- `pages/*.html`（6 个）：主内容容器统一 `id="main"`（skip-link 目标）；extract.html 修复嵌套 label。
- `tests/test_ui_accessibility.py`（新增 8 例）：固化零 CDN、焦点环、触摸目标、reduced-motion、四断点、语义色符号、导航可达属性、spinner 隐藏。
- `README.md`：Web 特性措辞由「零 JavaScript」修正为「无 JS 框架、离线可用、支持键盘可达性」。

## 引入 Vue 3 + Naive UI（本地化 + SSR 骨架渐进接管）

### 背景与决策
- 用户要求引入 Naive UI 组件。因其依赖 Vue 3 运行时，与「离线完整可用」冲突，经询问确认方案为：**本地化资源 + 全量 Vue 化重写**。
- 关键调研结论：所有测试断言都作用于服务端 `handle_request` 返回的 body 字符串，不执行浏览器 JS。故架构定为 **SSR 骨架完整保留（零回归）+ Vue 3/Naive UI 浏览器端渐进接管视觉与交互**，而非清空 SSR 让其消失。

### 落地改动
- `webui/`（新增，构建期）：package.json（vue 3.5.13 / naive-ui 2.45.3 / esbuild / jsdom）、build.mjs（esbuild IIFE、alias vue→vue/dist/vue.esm-bundler 带编译器、globalName=DataCleanUI）、entry.js（按需导出 NForm/NInput/NSelect/NButton/NCard/NDataTable/NTag/NAlert/NMessageProvider 等组件）、dump-pages.py（导出真实 SSR 页面供 jsdom）、verify-mount.mjs / verify-submit.mjs（jsdom 验证）。
- `static/vendor/`（新增，运行时产物）：naive-vue.js（约 896 KiB，含 Vue 编译器 + Naive UI，CSS-in-JS 自注入，无运行时 CDN 请求——URL 字面量仅为 SVG namespace / 文档链接文案）、app.js（按 `data-dc-page` 挂载各页组件树；从 SSR DOM 读取初始数据；提交复用原生 form POST 保持字段名/action 一致）。
- `webapp.py`：`render()` 注入 `data-dc-page` + 本地 bundle/`<script>`；新增 `/static/vendor/<file>` 路由（白名单 naive-vue.js/app.js，拒绝目录穿越）；Flask 与标准库均经 handle_request 故路由通用。
- `static/style.css`：`body.dc-vue-ready` 时隐藏 SSR 视觉层（无 JS / 挂载失败时仍显示 SSR，测试与非 JS 场景不受影响）。
- `tests/test_naive_ui_layer.py`（新增 5 例）：固化 vendor 路由、白名单、页面注入标记、app.js 契约字段。
- `.gitignore`：忽略 `webui/node_modules/`，保留 package-lock.json。
- `README.md`：更新顶部定位、Web 工作台说明（SSR+渐进接管架构、webui 构建/验证命令）、架构表、测试段落与基线。

### 关键修复
- jsdom 提交测试发现 `submitWith` 丢弃空值字段，导致 `/execute`、`/rules/save` 的 `rule_json` 丢失；改为保留空字段（与原生 form 行为一致）后 6/6 通过。

### 验证
- compileall 通过；全量离线 **834 passed / 28 skipped / 12 deselected**（上轮 829，+5），零回归。
- jsdom：4/4 页挂载成功、零 JS 错误；6/6 提交契约通过。
- `tests/test_naive_ui_layer.py` 5/5 通过。

### 约定
- 运行时不得引入任何 CDN；前端组件源码改动后需 `cd webui && npm run build` 重建 bundle，`npm run verify` 回归。
- 保持 SSR 骨架与所有服务端契约字符串不变——测试与非 JS 基线依赖它；Vue 只在 `dc-vue-ready` 后接管视觉层。
- Node/npm 仅为构建期依赖，不是运行 DataClean 的前置条件；vendor 产物随仓库提供。
